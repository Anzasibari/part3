# TRIO Hospitality Website

## 1. Project Overview

TRIO Hospitality is a multi-page website designed to present hospitality and event management services. The website allows visitors to learn about the company, view its previous work, read hospitality-related articles, make booking requests and send general enquiries.

The website focuses on providing visitors with a professional and simple way to explore TRIO Hospitality's services.

## 2. Website Pages

The website consists of six main HTML pages:

### 1. Home Page (`index.html`)
The home page introduces TRIO Hospitality and provides an overview of the business.

**Features:**
- Introduction to TRIO Hospitality.
- Overview of hospitality services.
- Featured projects and previous work.
- Company approach and benefits.
- Information about the company's location.
- Partnership information.

### 2. About Page (`about.html`)
The About page provides information about the company, its background and its values.

**Features:**
- Company story and introduction.
- Company philosophy.
- Core values: Trust, Reliability and Innovation.
- Company facts and achievements.
- Team information.

### 3. Portfolio Page (`portfolio.html`)
The Portfolio page displays examples of events and projects handled by TRIO Hospitality.

**Features:**
- Corporate gala events.
- Luxury weddings.
- International conferences.
- Project images and descriptions.

### 4. Blog Page (`Blog.html`)
The Blog page shares articles and information related to hospitality and event management.

**Features:**
- Featured blog article.
- Latest articles.
- Guest experience information.
- Sustainability in hospitality.
- Corporate event-related content.
- Blog categories.

### 5. Bookings Page (`Bookings.html`)
The Bookings page allows visitors to submit event booking requests.

**Features:**
- Full name and company details.
- Email address and phone number.
- Event type selection.
- Number of guests.
- Preferred event date.
- Budget information.
- Additional message section.
- Information about the expected response time.

### 6. Enquiry Page (`enquiry.html`)
The Enquiry page allows visitors to contact TRIO Hospitality with general questions.

**Features:**
- Visitor name field.
- Email address field.
- General enquiry field.
- Contact information.

## 3. Technologies Used

The website uses the following technologies:

- **HTML5:** Used to create the structure and content of the website.
- **CSS3:** Used to style the pages and improve the website's appearance.
- **JavaScript:** Used to add interactive functionality.
- **Font Awesome:** Used for icons throughout the website.

## 4. Project Folder Structure

The project should be organised as follows:

```text
TRIO-Hospitality/
│
├── index.html
├── about.html
├── portfolio.html
├── Blog.html
├── Bookings.html
├── enquiry.html
│
├── css/
│   └── style.css
│
├── js/
│   └── script.js
│
└── image/
    └── website-images
```

**Note:** The CSS, JavaScript and image folders contain supporting files referenced by the HTML pages. Make sure these files are included in the project for the website to display and function correctly.

## 5. How to Run the Website

Follow these steps to open the website:

1. Download or copy the TRIO Hospitality project folder.
2. Open the folder using Visual Studio Code.
3. Make sure all HTML, CSS, JavaScript and image files are in their correct folders.
4. Open the `index.html` file.
5. Run the file using a web browser or the Live Server extension in Visual Studio Code.
6. Use the navigation menu to move between the different website pages.

## 6. Main Website Features

The TRIO Hospitality website provides:

- A multi-page website with easy navigation.
- Company information and background.
- A portfolio showcasing previous events.
- A blog section with hospitality-related articles.
- An event booking request form.
- A general enquiry form.
- Images and icons to improve the website's appearance.

## 7. Purpose of the Website

The main purpose of the TRIO Hospitality website is to create an online presence for the business. It helps potential clients understand the company's services, explore previous projects and contact the business for event bookings or general enquiries.

## 8. Conclusion

The TRIO Hospitality website provides a professional online platform for presenting the company's services and information. Its six pages help visitors learn about the business, explore its portfolio, read articles and submit booking requests or enquiries.

The website is designed to make it easier for potential clients to connect with TRIO Hospitality.
